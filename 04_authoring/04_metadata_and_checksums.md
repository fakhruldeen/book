## شريط البيانات التوثيقية أسفل كل صفحة

يحتوي كل مقال أو فصل في الكتاب على شريط توثيقي مدمج يظهر قبل التذييل مباشرة عبر المكون المضمن `_includes/page_meta.html`.

يتضمن هذا الشريط:
1. **تاريخ وتوقيت النشر الدقيق:** بتنسيق `YYYY-MM-DD HH:mm:ss` مع المنطقة الزمنية (`+03:00`).
2. **اسم مؤلف الصفحة:** يُستخرج تلقائيًا من ترويسة الصفحة أو من القيمة الافتراضية في `_config.yml`.
3. **البصمة الرقمية المشفرة (SHA-256):** قيمة تجزئة تُحسب لمحتوى الصفحة فقط لضمان التحقق من سلامتها.
4. **زر النسخ السريع:** يتيح للقارئ نسخ البصمة الرقمية إلى الحافظة بنقرة زر واحدة للتحقق منها لاحقًا.

## كيف تُحسب البصمة الرقمية في المتصفح؟

يعتمد القالب على واجهة **Web Crypto API** القياسية المدعومة أصليًا في كافة المتصفحات الحديثة (`crypto.subtle.digest`):

```javascript
// حساب بصمة SHA-256 لنص الصفحة في جانب العميل
async function calculateContentSha256(text) {
  const encoder = new TextEncoder();
  const data = encoder.encode(text);
  const hashBuffer = await crypto.subtle.digest("SHA-256", data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  const hashHex = hashArray.map(b => b.toString(16).padStart(2, "0")).join("");
  return hashHex;
}
```

## مطابقة البصمة والتحقق من التعديلات

عندما يقوم القارئ بالتحقق من بصمة الصفحة:
- إذا تطابقت البصمة، فهذا إثبات قاطع بأن محتوى الصفحة مطابق تمامًا لما نشره المؤلف ولم يطرأ عليه أي تغيير.
- إذا عُدلت أي كلمة أو حركة إعرابية في النص، تتغير البصمة الرقمية بالكامل (تأثير الانهيار - Avalanche effect).
