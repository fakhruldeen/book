## قلب القالب: ملف التكوين `_config.yml`

يُدار الكتاب بنسبة 100٪ من خلال ملف التكوين القياسي `_config.yml`. لن تحتاج أبدًا لتعديل ملفات HTML أو جافاسكريبت لتغيير عنوان الكتاب أو اسم المؤلف أو روابط التنزيل.

### 1. بيانات وهوية الكتاب الأساسية

```yaml
# هوية الكتاب الأساسية
title: "عنوان كتابك هنا"
subtitle: "العنوان الفرعي الشارح لكتابك"
description: "نبذة تعريفية شاملة تُستخدم في محركات البحث وبطاقات المشاركة"
tagline: "عبارة ترويجية أو إرشادية مختصرة"
edition: "الطبعة الأولى 1.0"
version: "1.0.0"
isbn: "978-0-0000-0000-0"       # رقم الإيداع الدولي
doi: "10.1000/182-your-book"     # المعرف الرقمي الدولي (اختياري)
lang: "ar"                       # لغة الكتاب (العربية)
dir: "rtl"                       # اتجاه العرض من اليمين لليسار

# تاريخ اعتماد ونشر الكتاب
book_timestamp: "2026-10-18T00:00:00+03:00"
book_date_formatted: "الأحد، ٦ جمادى الأولى ١٤٤٨ هـ / ١٨ أكتوبر ٢٠٢٦ م"

# صورة خلفية الغلاف (اختياري: تظهر خلف صندوق الغلاف وتُستخدم في بطاقات المشاركة)
cover_image: "/assets/images/cover.svg"    # اتركه فارغًا للرجوع للتدرج اللوني الافتراضي
social_image: "/assets/images/cover.svg"   # بطاقة المشاركة المربعة/العريضة لمحركات البحث وشبكات التواصل (1200x630)
favicon: "/assets/images/favicon.svg"      # أيقونة التبويب في المتصفح
keywords: "كتابك, وسوم البحث, مفتاحية"     # كلمات دلالية لمحركات البحث
```

---

### 2. بيانات المؤلف والتواصل

```yaml
author:
  name: "اسمك الكريم"
  latin_name: "Your Name in English"
  email: "your-email@example.com"
  bio: "نبذة مختصرة عن خبرتك وسيرتك الذاتية ومؤلفاتك..."
  role: "المؤلف الرئيسي"
  avatar: "/assets/images/author.svg"
  website: "https://yourwebsite.com"
  location: "الرياض، المملكة العربية السعودية"
```

### 3. مصفوفة المساهمين وحفظ الحقوق عبر المراحل الخمس

يتيح القالب توثيق جهود كافة المساهمين لحفظ حقوقهم الأدبية والفكرية:

```yaml
contributors:
  authoring:
    title: "مرحلة التأليف والكتابة"
    roles:
      - key: "authors"
        singular: "المؤلف"
        plural: "المؤلفون"
        people:
          - name: "زيد العمري"
            latin_name: "Zaid Al-Omari"
            role_detail: "تأليف المتن الأساسي"
            orcid: "0009-0001-2345-6789"
            rights_statement: "صاحب الحقوق الفكرية والأدبية للنص."
  reviewing:
    title: "مرحلة المراجعة والتحكيم"
    roles:
      - key: "style_editor"
        singular: "محرر الأسلوب"
        plural: "محررو الأسلوب"    # المعالجة النحوية السليمة
        people: []                 # يُخفى تلقائيًا إن لم يوجد أحد
```

---

### 4. إعدادات النشر على GitHub Pages

- إذا كان موقعك موقع مشروع: `baseurl: "/my-book"`
- إذا كان موقعك هو النطاق الأساسي: `baseurl: ""`
- الرابط الكامل: `url: "https://<username>.github.io"`
- الروابط النظيفة دون `.html`: `permalink: pretty`
