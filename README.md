# كتاب Markdown التفاعلي ومختبر الطباعة العربية

قالب متكامل لكتاب عربي تفاعلي مبني بصيغة Markdown ومخصص للنشر المباشر عبر **GitHub Pages** ومحرك **Jekyll** المدمج، بدون الحاجة لأي تجميع محلي أو خطوات معقدة.

🌐 **الرابط على GitHub Pages:** [https://fakhruldeen.github.io/book](https://fakhruldeen.github.io/book)

---

## 🌟 أبرز القدرات والميزات

- 📖 **تنضيد عربي أصيل (RTL):**
  - خطوط *Cairo* للعناوين والواجهات، و*Noto Naskh Arabic* لمتن القراءة الطويل.
  - دعم كامل للتشكيل، والتنوين، وتراكم الحركات الرأسية دون تداخل.
  - دعم نصوص الشعر العربي العمودي (صدر وعجز) متوازنة ومتجاوبة مع مختلف الشاشات.
  - معالجة النصوص ثنائية الاتجاه (BiDi) لدمج المصطلحات الإنجليزية واللاتينية والأرقام دون اختلال في الأقواس أو علامات الترقيم.
- 🎯 **اختبارات تفاعلية ذكية (5 أنواع من الأسئلة):**
  - اختيار من متعدد (`mcq`) مع أحرف عربية (أ، ب، ج، د).
  - اختيار فردي/صح وخطأ (`radio`).
  - اختيار متعدد (`check`).
  - إجابة رقمية (`number`) تدعم الأرقام العربية المشرقية والمغربية مع هامش تسامح.
  - مقياس تقييم رأي (`scale`).
- 🔓 **نظام تقدّم غير مانع:**
  - إنجاز الاختبار بنسبة ٨٠٪ (أو النسبة المحددة) يفتح ويضيء زر «التالي».
  - الاختبار اختياري والقارئ حر في الانتقال في أي وقت.
  - حفظ التقدم في ذاكرة المتصفح المحلية (`localStorage`).
  - شريط إنجاز علوي وشارة نسبة في شريط التنقل وصفحة الغلاف.
- 🌓 **وضع ليلي متكامل (Dark Mode):**
  - تبديل فوري يحفظ التفضيل محلياً ويعيد تهيئة ألوان المخططات تلقائيًا.
- 📊 **مخططات Mermaid تفاعلية:**
  - مخططات انسيابية (Flowcharts)، مخططات تسلسل (Sequence)، جانت (Gantt)، ومخططات دائرية (Pie).
- 📐 **معادلات رياضية (LaTeX / MathJax):**
  - معادلات سطرية وكتلية، تكاملات، مصفوفات، ومتسلسلات.
- 💻 **كتل برمجية متطورة:**
  - تلوين برمجي بأكثر من لغة (JavaScript, Python, Rust, SQL, Bash...) مع زر نسخ فوري وشارة للغة.
- 📑 **فهرس تفاعلي وبحث لحظي:**
  - تصفية فورية لعناوين الفهرس وشارات علامة الإنجاز (✓).

## 🗂️ هيكل الكتاب ومستويات العناوين

تُستنبط أرقام الصفحات ومستويات العناوين ومسار التصفح (Breadcrumbs) تلقائيًا من مسارات المجلدات والملفات:

| المسار | الرقم المرجعي | مستوى العنوان | الوصف |
|---|:---:|:---:|---|
| `01_basics.md` | `01` | `h2` | فصل رئيسي |
| `01_basics/02_lists.md` | `01.02` | `h3` | قسم داخل فصل |
| `01_basics/02_lists/01_lists.md` | `01.02.01` | `h4` | قسم فرعي |
| `01_basics/02_lists/02_tables/01_alignment.md` | `01.02.02.01` | `h5` | قسم فرعي فرعي |

> [!TIP]
> يوضع ملف الصفحة الأب دائمًا بجانب المجلد الذي يحمل نفس اسمه ويحتوي أبناءه (مثلاً `02_lists.md` بجانب المجلد `02_lists/`).

## 📝 ترويسة الصفحة (Front Matter) وكتابة الاختبارات

```yaml
---
title: عنوان الصفحة باللغة العربية
pass: 80            # اختياري: نسبة النجاح المطلوبة لفتح زر التالي (الافتراضي 80%)
quiz:
  - type: mcq
    q: "نص السؤال؟"
    options: ["الخيار الأول", "الخيار الثاني", "الخيار الثالث"]
    answer: 2       # رقم الخيار الصحيح (يبدأ العد من 1)
    explain: "شرح يظهر للقارئ بعد التحقق"
  - type: radio
    q: "العبارة صحيحة؟"
    options: ["صحيح", "خطأ"]
    answer: 1
  - type: check
    q: "اختر الإجابات الصحيحة:"
    options: ["أ", "ب", "ج"]
    answer: [1, 3]
  - type: number
    q: "أدخل القيمة الرقمية الناتجة:"
    answer: 42
    tolerance: 0.5  # اختياري
  - type: scale
    q: "ما مدى تقييمك لهذا القسم؟"
    min: 1
    max: 5
    low: "مبتدئ"
    high: "خبير"
---
```

## 🚀 النشر على GitHub Pages

1. ادفع ملفات المستودع إلى GitHub:
   ```bash
   git add .
   git commit -m "feat: complete interactive arabic book template"
   git push origin main
   ```
2. في GitHub، توجه إلى:
   **Settings** ← **Pages**
3. تحت **Build and deployment**:
   - **Source:** اختر `Deploy from a branch`
   - **Branch:** اختر `main` والمجلد `/ (root)`
   - اضغط **Save**
4. بعد اكتمال البناء، سيكون كتابك متاحًا فورًا على الرابط:
   `https://fakhruldeen.github.io/book`
