## المراجع والمصادر المعتمدة

توثق هذه القائمة المصادر الببليوغرافية والمعايير القياسية المعتمدة في تصميم هذا القالب وتنضيد محتواه الرقمي وفق أسلوب التوثيق الأكاديمي الدولي (APA 7th):

1. **Jekyll Development Team.** (2024). *Jekyll Documentation: Configuration, Collections, and Themes*. [https://jekyllrb.com/docs/](https://jekyllrb.com/docs/)
2. **GitHub Pages Documentation.** (2025). *Publishing Static Sites from a GitHub Repository*. GitHub Docs. [https://docs.github.com/pages](https://docs.github.com/pages)
3. **Unicode Consortium.** (2024). *Unicode Standard Annex #9: Unicode Bidirectional Algorithm (UAX #9)*. Unicode Technical Report. [https://www.unicode.org/reports/tr9/](https://www.unicode.org/reports/tr9/)
4. **W3C Internationalization Working Group.** (2023). *Authoring HTML: Handling Right-to-Left Scripts and Bidirectional Text*. World Wide Web Consortium. [https://www.w3.org/International/articles/inline-bidi-markup/](https://www.w3.org/International/articles/inline-bidi-markup/)
5. **Kramdown Core Team.** (2024). *Kramdown Syntax Guide: GitHub-Flavored Markdown and Extensions*. [https://kramdown.gettalong.org/syntax.html](https://kramdown.gettalong.org/syntax.html)
6. **Sverre, K., & Mermaid Community.** (2024). *Mermaid: Generation of diagrams and flowcharts from text*. [https://mermaid.js.org/](https://mermaid.js.org/)
7. **MathJax Consortium.** (2023). *MathJax: Beautiful math in all browsers via LaTeX syntax*. [https://www.mathjax.org/](https://www.mathjax.org/)
8. **فخر الدين، محمد.** (2026). *هندسة النشر الرقمي للكتب العربية التفاعلية*. دار النشر التقنية. رقم الإيداع الدولي: `{{ site.isbn }}`، المعرف الرقمي: `{{ site.doi }}`.
