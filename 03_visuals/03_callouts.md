تُساعد صناديق التنبيه (Alerts) على توجيه انتباه القارئ للملاحظات الهامة، الإرشادات التحذيرية، والفوائد الإضافية بألوان مميزة تدعم الوضعين النهاري والليلي.

---

### تنبيه الملاحظة (`> [!NOTE]`)

> [!NOTE]
> هذا صندوق ملاحظة زرقاء (`NOTE`). يُستخدم لعرض معلومات توضيحية أو سياقية مكملة للفكرة الأساسية دون قطع حبل أفكار القارئ.

---

### تنبيه النصيحة (`> [!TIP]`)

> [!TIP]
> نصيحة ذكية (`TIP` بالأخضر): يمكنك تصفح صفحات الكتاب باستخدام لوحة المفاتيح والتركيز التلقائي على الروابط.

---

### تنبيه الأهمية (`> [!IMPORTANT]`)

> [!IMPORTANT]
> معلومة جوهرية (`IMPORTANT` بالبنفسجي): تأكد من صحة إعدادات `baseurl` في ملف `_config.yml` لضمان عمل كافة الروابط على GitHub Pages.

---

### تنبيه التحذير (`> [!WARNING]`)

> [!WARNING]
> تنبيه تحذيري (`WARNING` بالأصفر/الكهرماني): لا ترفع أسرار الواجهات أو المفاتيح الحساسة (API Keys) في مستودعات Git العامة.

---

### تنبيه الخطر (`> [!CAUTION]`)

> [!CAUTION]
> تحذير شديد الخطورة (`CAUTION` بالأحمر): هذا الإجراء يؤدي إلى حذف البيانات نهائيًا ولا يمكن التراجع عنه.

---

### الأقسام القابلة للطي (`<details>`)

تُستخدم لتضمين حلول التمارين، الإجابات، أو الشيفرات الموسعة دون زيادة طول الصفحة:

<details>
<summary>اضغط هنا للكشف عن حل التمرين البرمجي</summary>

يمكنك كتابة كود كامل أو تنسيقات Markdown داخل الطي:

```python
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

# أول 10 أرقام من متتالية فيبوناتشي
print(list(fibonacci(10)))
```

> [!TIP]
> حتى التنبيهات وصناديق الملاحظات تعمل بسلاسة تامة داخل الأقسام القابلة للطي!

</details>

<details>
<summary>عرض تفاصيل تقنية إضافية حول التخزين المحلي</summary>

تُخزن بيانات الإنجاز في مفتاح `book:v1` في كائن `localStorage` بالمتصفح كـ JSON بالشكل التالي:

```json
{
  "passed": {
    "01": 100,
    "01.01": 100,
    "02": 85
  }
}
```
</details>
